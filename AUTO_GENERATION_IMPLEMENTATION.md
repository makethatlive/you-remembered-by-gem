# Auto Gift Generation + AI API Tracking Implementation

## Summary
Implemented automatic gift list generation at 6-week mark before birthdays, plus comprehensive AI API call tracking system for monitoring Claude AI usage and costs.

---

## Features Implemented

### 1. Auto Gift Generation (6-Week Logic)

#### On Recipient Create
- When a recipient is added via POST `/api/recipients`, the system calculates days until their birthday
- **If ≤ 42 days away (6 weeks)**: Gift list is auto-generated immediately (async)
- **If > 42 days away**: Gift list will be auto-generated by daily scheduled job

#### Daily Scheduled Job
- **Schedule**: Every day at 9:00 AM (Europe/London timezone)
- **Process**:
  1. Finds all recipients with birthdays 41-43 days away
  2. Checks if they already have a gift list this year
  3. Auto-generates gift lists for those who don't
- **Job Location**: `server/jobs/auto-gift-generation.js`
- **Integration**: Started automatically via `server/jobs/email-scheduler.js`

#### Helper Function
```javascript
calculateDaysUntilBirthday(day, month)
// Returns: Number of days until next birthday occurrence
```

### 2. AI API Call Logging

#### Database Model
New model: `AIApiCallLog`
- Tracks all Claude AI API calls
- Fields: callType, status, provider, model, tokens, cost, duration, context
- Linked to: Recipient, GiftList

#### API Call Logger Service
**Location**: `server/services/ai/api-call-logger.js`

**Features**:
- `logCall()` - Records API call with metadata
- `calculateCost()` - Computes cost based on provider pricing
- `getLogs()` - Query logs with filters
- `getStats()` - Aggregate statistics

**Cost Calculations**:
- Claude: $3/1M input tokens, $15/1M output tokens
- Gemini: $1.25/1M input tokens, $5/1M output tokens

#### Claude Client Integration
**Location**: `server/services/ai/claude-client.js`

**Changes**:
- Added `prisma` parameter to constructor
- Added `setContext()` method for tracking recipient/giftList context
- Wrapped `generateStructuredContent()` with automatic logging
- Logs: tokens used, cost, duration, status, request/response snippets

**Context Setting**:
- Profile analysis: `claudeClient.setContext({ callType: 'PROFILE_ANALYSIS', recipientId })`
- Gift selection: `claudeClient.setContext({ callType: 'GIFT_SELECTION', recipientId, giftListId })`

### 3. Admin API Endpoints

#### GET /api/admin/ai-logs
**Purpose**: Retrieve paginated AI call logs with filters

**Query Parameters**:
- `page` - Page number (default: 1)
- `limit` - Items per page (default: 50, max: 200)
- `status` - Filter by SUCCESS, ERROR, TIMEOUT
- `callType` - Filter by PROFILE_ANALYSIS, GIFT_SELECTION, PRODUCT_CLASSIFICATION
- `recipientId` - Filter by recipient
- `giftListId` - Filter by gift list
- `startDate` - Filter from date (ISO)
- `endDate` - Filter to date (ISO)

**Response**:
```json
{
  "logs": [...],
  "pagination": {
    "page": 1,
    "limit": 50,
    "total": 150,
    "totalPages": 3,
    "hasNext": true,
    "hasPrev": false
  }
}
```

#### GET /api/admin/ai-stats
**Purpose**: Get aggregated AI API statistics

**Query Parameters**:
- `startDate` - Filter from date (ISO)
- `endDate` - Filter to date (ISO)
- `groupBy` - Group by 'day', 'week', or 'month'

**Response**:
```json
{
  "overall": {
    "totalCalls": 150,
    "successfulCalls": 145,
    "errorCalls": 5,
    "successRate": "96.67",
    "totalCost": 2.4567,
    "totalInputTokens": 45000,
    "totalOutputTokens": 12000,
    "totalTokens": 57000,
    "avgDuration": 1234.56
  },
  "byCallType": {...},
  "byProvider": {...},
  "timeSeries": [...]
}
```

## Usage

### For Administrators

1. **View AI Logs**:
   - Go to Admin Dashboard
   - Click "AI Logs" tab or quick link
   - Filter by status, call type, or date range
   - Review statistics and individual calls

2. **Monitor Costs**:
   - Check "Total Cost" stat card for lifetime cost
   - Use date filters to see costs for specific periods
   - Review by call type to see which operations cost most

3. **Identify Issues**:
   - Filter by status = "ERROR" to see failed calls
   - Check error messages in logs
   - Use recipient filter to debug specific recipient issues

### For Developers

1. **Add Logging to New AI Calls**:
```javascript
// Set context before calling AI
claudeClient.setContext({
  callType: 'YOUR_CALL_TYPE',
  recipientId: recipientId,
  giftListId: giftListId // optional
});

// Make AI call (logging happens automatically)
const result = await claudeClient.generateStructuredContent(...);
```

2. **Manual Testing**:
```bash
# Test auto-generation logic
node test-auto-generation.js

# Test daily job manually
node -e "import('./server/jobs/auto-gift-generation.js').then(m => m.autoGenerateJob())"
```
